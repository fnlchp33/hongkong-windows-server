**1核1G能不能跑Windows**

技术上能装，但实际用起来会很卡。Windows Server系统进程占内存较多，1G内存装完系统后剩余空间有限，跑任何业务都会捉襟见肘。如果一定要用Windows，建议从2核4G起步，这个配置才能保证基本流畅。

**远程桌面怎么连**

Windows服务器通过RDP（远程桌面协议）连接，这是Windows系统自带的功能，不需要额外配置。在本地电脑打开"远程桌面连接"，输入服务器IP和管理员账号密码就能登录。恒创还提供控制台直接访问功能，即使网络中断也能临时维护。
